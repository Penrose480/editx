# EDITX

A simple, minimal, efficient text editor inspired by nano. 

## INSTALLATION

Clone or copy symlinks invidually. After do the following:

```bash
# (may have to run as root)
make clean install
```
## REMOVAL

```
# (may have to run as root)
make clean uninstall
```

## USAGE

### Run the editor 
```bash
./editx
```
### Edit a file:
```bash
./editx [INSERT FILENAME HERE]
```

### Keybinds

CTRL + q: quit
CTRL + s: save 
CTRL + f: find
